# autolisting

`autolisting` — это утилита командной строки для Windows, предназначенная для автоматического создания полного листинга исходного кода проекта. Она рекурсивно обходит указанную папку, собирает структуру проекта (дерево папок и файлов) и содержимое файлов с определёнными расширениями, а затем копирует весь результат в буфер обмена для удобного вставления (например, в чат с нейросетью).

## Особенности

*   **Полный листинг:** Выводит как структуру проекта, так и содержимое кода.
*   **Красивое дерево:** Структура папок отображается в виде интуитивно понятного дерева с символами `├`, `└`, `│`.
*   **Фильтрация файлов:** Обрабатывает только файлы с определёнными расширениями (по умолчанию `.py`, `.js`, `.dart`, `.html`, `.css`, `.json`, `.md`, `.txt`, `.sh`, `.cpp`, `.c`, `.h`, `.ts`, `.jsx`, `.tsx`).
*   **Настройка через файл:** Позволяет включать (`include`) или исключать (`exclude`) определённые папки и файлы из листинга с помощью файла настроек, который располагается в корневой папке проекта (создается вами) `.autolisting`.
*   **Копирование в буфер:** Результат сразу готов к вставке — копируется в буфер обмена после выполнения.
*   **Полностью на русском:** Интерфейс и вывод утилиты на русском языке.

## Установка

1.  Скачайте последнюю версию исполняемого файла `autolisting.exe` из релизов или скомпилируйте его самостоятельно (см. раздел "Сборка").
2.  Поместите `autolisting.exe` в удобное место, например, в папку, добавленную в переменную окружения `PATH`, чтобы можно было запускать команду `autolisting` из любого места.
    *   Или просто положите `autolisting.exe` в папку проекта, в котором хотите выполнить листинг, и запускайте как `.\autolisting.exe`.

Примечание:
* Для более удобного использования можно переименовать файл `autolisting.exe` в `al.exe`, тогда вместо команды `autolisting` нужно будет вводить `al`. Если переименовать файл в свое название, команда изменится соответствующе. Так же можно скопировать и вставить в одну папку `autolisting.exe`, чтобы создать два одинаковых файла, а после переименовать второй файл, после чего утилита будет вызываться по обоим названиям файлов

## Использование

1.  Откройте командную строку (CMD) в папке проекта, который нужно просканировать.
    ```
    cd (полный путь к папке)
    ```
2.  Выполните команду:
    ```bash
    autolisting
    ```
    или то имя файла на которое вы изменили `autolisting.exe` (например, `al.exe`):
    ```bash
    al
    ```

    или если исполняемый файл находится в той же папке:
    ```bash
    .\autolisting.exe
    ```
3.  Вставьте содержимое буфера обмена (обычно `Ctrl+V`) туда, где нужно.


## Настройка через `.autolisting`

Файл `.autolisting` должен находиться в **корне папки**, откуда запускается утилита.

### Синтаксис

*   **Режим:**
    *   `mode include` — В листинг попадут **только** файлы и папки, указанные в списке ниже. Всё остальное будет исключено.
    *   `mode exclude` — В листинг попадёт **всё**, **кроме** файлов и папок, указанных в списке ниже.
*   **Пути:** Укажите пути к файлам или папкам, относительно корня проекта. Используйте формат `./dir/subdir` или `./file.ext`.
    *   Пример: `./lib`
    *   Пример: `./src/utils/helper.py`
*   **Комментарии:**
    *   Однострочный комментарий: строка начинается с `|`.
        *   Пример: `| Это комментарий`
    *   Многострочный комментарий: начинается с `||` и заканчивается `||`.
        *   Пример:
            ```
            ||
            Это
            многострочный
            комментарий
            ||
            ```
    *   Комментарий в строке с путём: Разделите путь и комментарий символом `|`.
        *   Пример: `./src | Включаем папку исходников`

### Примеры

**Пример 1: Включить только `src` и `README.md`**

`.autolisting`:
```ini
mode include
./src
./README.md
```
**Пример 2: Включить всё, кроме `src` и `README.md` с комментариями**

`.autolisting`:
```ini
mode exclude

|| многострочный комментарий можно использовать для
комментирования кода
./src
./README.md
||


./src | картинки, ненужные файлы
./README.md | нейросети не нужен текст этого файла
```

## Сборка из исходников

1. Убедитесь, что у вас установлен Python 3.x.
2. Установите `pyinstaller`:
```bash
pip install pyinstaller
```
3. Скачайте файл autolisting.py.
4. Выполните команду для сборки:
```bash
pyinstaller --onefile --noconsole autolisting.py
```

Результат (`autolisting.exe`) появится в папке `dist/`.
